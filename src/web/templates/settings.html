🧭 Key wizard: where to get each key, step by step

Non-technical, click-by-click. Websites move their menus around, so if a label is not exactly the same, pick the closest one. Each step ends with a box you paste into the table below.

1 · OpenAI (writes captions, makes images and voice-overs)

  1. Go to platform.openai.com and sign in (or create an account).
  2. Add money first or every call fails: Settings → Billing → Add payment details → add about $10 of credit. A caption costs well under one cent, an image about 4 cents, a voice-over a few cents.
  3. Open Dashboard → API keys → Create new secret key → name it social-automation → Create.
  4. Copy the key that starts with sk-. It is shown once. If you lose it, make a new one.
  5. Paste it in the OPENAI_API_KEY row below and click Save.

2 · Meta (posts to your Facebook Pages and Instagram)

Create the app with the Other use case and type Business (the "Facebook Login" use case cannot get Page permissions).

You need: a Facebook Page you manage, and an Instagram Business or Creator account connected to that Page (Instagram app → Settings → Business tools → Connect a Facebook Page).

  1. Go to developers.facebook.com → My Apps → Create App. Use case: Other → type: Business → name it Social Automation → Create app.
  2. Open Tools → Graph API Explorer. On the right: pick your new app under Meta App, and User Token under User or Page.
  3. Under Permissions add exactly these (copy them one by one, or paste the list):
    pages_show_list, pages_read_engagement, pages_manage_posts, pages_manage_metadata, instagram_basic, instagram_content_publish, business_management
  4. Click Generate Access Token, log in, tick your Page and Instagram account, and allow everything asked.
  5. Make the token long-lived: open Tools → Access Token Debugger, paste the token, Debug → Extend Access Token → copy the new one back into the Explorer's token box.
  6. Paste that extended token into Connected Facebook Pages above and click Connect Pages. The tool fetches your Pages, their tokens and Instagram accounts by itself. Done: no IDs to copy.

For clients' pages: while your app is in Development mode it only works for people with a role on the app. Either add the client as a Tester (App Dashboard → App roles → they must accept), or submit the permissions for App Review, which takes Meta a few weeks.

3 · Image hosting (Instagram needs a public link to the image)

Quick (testing only): Imgur.

  1. Sign in at imgur.com, then open api.imgur.com/oauth2/addclient.
  2. Authorization type: Anonymous usage without user authorization. Fill in any name and your email → Submit.
  3. Copy the Client ID (not the secret) into IMGUR_CLIENT_ID.

Proper (needed for video and for client work): Cloudflare R2.

  1. At dash.cloudflare.com → R2 Object Storage → Create bucket (name: social-media).
  2. Open the bucket → Settings → Public access → connect a custom domain you own (for example media.yourdomain.com). Put https://media.yourdomain.com into R2_PUBLIC_URL.
  3. Back on the R2 page → Manage R2 API Tokens → Create API token → permission Object Read & Write → Create. Copy Access Key ID → R2_ACCESS_KEY_ID, Secret Access Key → R2_SECRET_ACCESS_KEY.
  4. The Account ID is shown on the right of the R2 overview page → R2_ACCOUNT_ID. Bucket name → R2_BUCKET. Then set MEDIA_HOST=r2 in .env.

5 · YouTube Shorts (your own channel, about 6 uploads a day free)

  1. Go to console.cloud.google.com → create a project named social-automation.
  2. Enable the YouTube Data API v3 for that project.
  3. OAuth consent screen: External, app name anything, your email, save. Under Test users add your own Google account.
  4. Credentials → Create credentials → OAuth client ID → type Web application → Authorised redirect URI:
    http://127.0.0.1:8000/settings/youtube/callback
  5. Copy the Client ID into YT_CLIENT_ID and the Client secret into YT_CLIENT_SECRET below, then click Connect YouTube above and approve.

6 · Threads (free extra channel, needs hosted media for photos/videos)

  1. In My Apps create another app with the use case Access the Threads API.
  2. In the app, open Use cases → Customize and add the permissions threads_basic and threads_content_publish.
  3. Under App roles → Roles add your Threads account as a Threads Tester, then accept the invite in the Threads app (Settings → Account → Website permissions).
  4. Back in the use case page, use Generate access token (or the Threads API user token tool) and paste it into THREADS_ACCESS_TOKEN below.

7 · TikTok (optional, slowest to set up)

  1. Register at developers.tiktok.com → Manage apps → Connect an app.
  2. Add the product Content Posting API and request the scope: video.publish. Add Login Kit too (it is how you get a token).
  3. Under Content Posting API, verify the domain your videos are hosted on (your R2 domain). TikTok only downloads from verified domains.
  4. Submit the app for review. Until it is approved, posts can only be private (the default here, TIKTOK_PRIVACY_LEVEL=SELF_ONLY).
  5. Log in through your app's Login Kit to get an access token and paste it into TIKTOK_ACCESS_TOKEN. It expires every 24 hours; a refresh step is on the to-do list.
